🚀 Опис проєкту.
Podium — це спеціалізована платформа для автоматизації проведення турнірів. Система розроблена для керування реєстрацією команд, ведення турнірних сіток та забезпечення прозорого оцінювання з боку журі в режимі реального часу.

🛠 Технологічний стек.
Backend: FastAPI (Python), SQLAlchemy ORM, SQLite.

Frontend: Vanilla JavaScript (ES6+), CSS3 (Flexbox/Grid), HTML5.

Security: JWT (JSON Web Tokens) для авторизації та хешування паролів.

Server: Uvicorn.

🏗 Архітектура та стан розробки.
Проєкт побудований на принципі розділення відповідальності (Separation of Concerns). Через стислі терміни розробки на етапі фінальної інтеграції виникли технічні складнощі зі злиттям компонентів (Integration Hell). Наразі репозиторій містить:

Backend Core (/backend): Повністю реалізована серверна логіка, включаючи моделі бази даних, асинхронні ендпоінти та систему аутентифікації. Документація API доступна через Swagger UI.

Frontend Interface (/frontend): Розроблено користувацький інтерфейс, логіку взаємодії з DOM та модулі зв'язку з API (api.js).

Database Schema: Продумана реляційна структура для збереження зв'язків між користувачами, ролями, турнірами та результатами.

⚠️ Технічна примітка.
Поточна версія демонструє модульну працездатність. Через конфлікти конфігурації середовища під час деплою, повна синхронна взаємодія фронтенду з бекендом потребує додаткового налаштування CORS-політик та валідації схем Pydantic. Код кожного модуля є відкритим для аудиту і демонструє глибину опрацювання бізнес-логіки.

🔮 Майбутні вдосконалення.
Завершення синхронізації клієнтської та серверної частин.

Впровадження WebSockets для миттєвого оновлення турнірних таблиць.

Розширення функціоналу для автоматичного генератора турнірних сіток (Single/Double Elimination).
